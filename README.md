# TuxAliasKit

مجموعه‌ای از aliasها و تابع‌های Bash برای لینوکس؛ شامل میانبرهای روزمره، Git، Docker، Laravel و تبدیل تصویر به WebP. توضیحات داخل فایل‌ها فارسی هستند تا کاربرد هر دستور روشن باشد.

نام پیشنهادی مخزن عمومی GitHub: `tux-alias-kit`.

توضیح پیشنهادی مخزن: `Persian-documented Bash aliases and helpers for Linux.`

موضوع‌های پیشنهادی GitHub: `bash`, `bash-aliases`, `linux`, `shell-scripts`, `terminal`, `docker`, `laravel`, `webp`.

## نصب

در ترمینال وارد پوشهٔ پروژه شوید و اجرا کنید:

```bash
bash install.sh
source ~/.bashrc
```

نصب‌کننده فایل aliasها را در `~/.local/share/tux-alias-kit/` قرار می‌دهد و یک بلوک مشخص و قابل‌تشخیص به `~/.bashrc` اضافه می‌کند. اگر `.bashrc` از قبل وجود داشته باشد، پیش از تغییر یک نسخهٔ پشتیبان کنار آن ساخته می‌شود. نصب دوباره، بلوک را تکراری نمی‌کند.

این پروژه برای Bash در توزیع‌های لینوکس آماده شده است. نصب را با کاربر عادی انجام دهید؛ برای خود نصب‌کننده نیازی به `sudo` نیست.

## دستورها

پس از بارگذاری دوبارهٔ Bash یا اجرای `source ~/.bashrc`، دستورهای داخل `aliases.sh` در دسترس هستند. برای دیدن aliasهای فعال:

```bash
alias
```

گروه‌های فعلی شامل میانبرهای عمومی، Git، Docker و چند دستور پایهٔ Laravel هستند. دستورهای Artisan فقط وقتی در پوشهٔ پروژهٔ Laravel اجرا شوند کاربرد دارند. `pa-migrate` مایگریشن‌ها را اجرا می‌کند؛ دستورهای مخرب و بازنشانی کامل پایگاه داده در این نسخه تعریف نشده‌اند.

### تبدیل تصویر به WebP

تابع `webp_convert` به برنامهٔ `cwebp` نیاز دارد. نصب آن را از بسته‌های توزیع لینوکس خود انجام دهید. نمونهٔ استفاده:

```bash
webp_convert photo.jpg
webp_convert photo.png 90
webp_convert photo.png result 75
```

کیفیت پیش‌فرض ۸۰ است. خروجی پیش‌فرض کنار تصویر اصلی با پسوند `.webp` ساخته می‌شود و فایل خروجی موجود بازنویسی نمی‌شود.

## حذف

برای غیرفعال‌کردن و حذف فایل نصب‌شده:

```bash
bash uninstall.sh
source ~/.bashrc
```

حذف‌کننده پیش از اعمال تغییر تأیید می‌گیرد و از `.bashrc` نیز نسخهٔ پشتیبان می‌سازد.

## دربارهٔ نسخهٔ شروع

دستورهای وابسته به مسیرهای شخصی، نام کاربری، ویرایشگر خاص یا تنظیمات یک سرور از نمونه کنار گذاشته شده‌اند تا پروژه روی سیستم‌های دیگر هم قابل استفاده باشد. دستورهایی که حذف فایل/منبع، تغییر گستردهٔ مجوزها یا ارتقای خودکار سیستم انجام می‌دهند نیز در مجموعهٔ پیش‌فرض قرار نگرفته‌اند.
